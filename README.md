# Cam Pro

Профессиональная камера для iPhone в стиле Blackmagic Camera — на SwiftUI + AVFoundation.

## Возможности

- **Фото и видео**: режимы ВИДЕО, ФОТО, SLO-MO (120/240 fps), TIMELAPSE
- **Качество записи**: 720p / 1080p / 4K, 24–240 fps (список зависит от камеры), HEVC / H.264, 3 уровня битрейта, стабилизация
- **Фото**: выбор разрешения (12 / 24 / 48 MP), RAW (DNG/ProRAW), вспышка
- **Ручное управление**: выдержка, ISO, EV, баланс белого (K + tint), фокус, зум, выбор объектива (0.5× / 1× / Tele / фронт)
- **Фильтры**: 16 встроенных LUT-образных looks + загрузка своих `.cube` LUT, регулировка интенсивности; применяются к превью, видео и фото
- **Сетки**: 3×3 (9 прямоугольников), 4×4, золотое сечение, диагонали, центр; рамки кадра 16:9 / 2.39:1 / 4:3 / 1:1 / 9:16; уровень-горизонт
- **Индикаторы**: гистограмма, аудио-метры, оставшееся место и битрейт
- Тап — фокус, щипок — зум

## Сборка IPA

Каждый push в `main` запускает workflow **Build IPA** (`.github/workflows/build-ipa.yml`).
Готовый **неподписанный** `Cam.ipa` лежит в артефакте `Cam-ipa` на странице запуска (Actions → Build IPA → Artifacts).
Скачай, распакуй zip и подпиши `.ipa` в ESign.

Проект генерируется через [XcodeGen](https://github.com/yonaskolb/XcodeGen) из `project.yml`.
Локально: `brew install xcodegen && xcodegen generate && open Cam.xcodeproj`.

Минимальная iOS — 17.0.
